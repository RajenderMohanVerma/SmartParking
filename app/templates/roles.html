ROLES & RESPONSIBILITIES

Admin and user control.

No website subscription. Users pay only parking fees. Admin sets rates and operations.

DRIVER

User can

  • Register, sign in, and reset password
  • Edit profile (name, phone, address)
  • Add vehicles and set a default vehicle
  • Search parking areas and reserve a slot
  • Pay parking fees for the booked session
  • Download QR pass and PDF receipt
  • Cancel a confirmed booking before check-in
  • View notifications and payment history

Users are charged parking fees only — not a plan to use the website.

OPERATOR

Admin can

  • View operations dashboard and reports
  • Activate or deactivate user accounts
  • Create parking areas and manage slots
  • Set hourly / daily parking fee rates
  • Create fee policies (amount + months/years validity)
  • Record and review parking payments
  • Verify QR / booking ID at entry
  • Check vehicles in and out

Admin decides how much parking costs and how long a rate card stays active.
